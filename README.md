# biliTv

**为 Android TV、电视盒子和安卓平板打造的 Bilibili 第三方客户端。**

biliTv 面向大屏观看场景，支持使用电视遥控器浏览和播放，也可以在安卓平板上触屏操作。

> 当前正式版：**0.12.20** · [下载 APK 与查看本次更新](https://github.com/lvsaber01/biliTv/releases/tag/v0.12.20)

## 可以做什么

- **观看视频**：浏览首页推荐、频道内容和排行榜，也可以搜索视频；支持观看历史、收藏和稍后再看等个人内容。
- **观看番剧**：进入番剧专区浏览日本动画和国创动画，可查看推荐、排行、索引、追番和放送表；在详情页选择不同季度和集数。
- **观看直播**：浏览直播分类和推荐，查看关注的直播间，也可以把房间加入本机收藏。
- **调整播放体验**：根据视频选择画质，并使用倍速、音轨、字幕和弹幕功能；弹幕的显示范围、速度、字号、透明度和密度可以调整。
- **管理个人内容**：登录后可查看观看历史、收藏、稍后再看、追番和关注内容。部分个人功能需要 Bilibili 账号。
- **个性化设置**：选择首页展示方式、常用频道和内容轨道，并设置播放画质、视频编码及弹幕偏好。

## 基本使用

- 打开应用后，选择视频、番剧或直播内容专区，再通过卡片进入详情或播放。
- 观看番剧时，可在详情页选择季度和集数；支持的续播选项会根据观看进度显示。
- 电视上使用方向键移动焦点、确认键进入或选择，返回键返回上一级；播放控制栏显示时，返回键优先收起控制栏。安卓平板可直接触屏操作。
- 浏览公开内容通常不需要登录；历史记录、个人收藏、关注等账号相关内容需要登录。

## 下载与安装

前往 [GitHub Releases](https://github.com/lvsaber01/biliTv/releases/latest) 下载当前正式版 APK，在 Android TV、电视盒子或安卓平板上安装。首次安装时，Android 可能会提示允许当前文件管理器安装应用。

每个版本的功能变化和安装包请查看 [GitHub Releases](https://github.com/lvsaber01/biliTv/releases)。
