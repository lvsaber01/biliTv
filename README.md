# biliTv

**为电视盒子、Android TV 和安卓平板打造的 Bilibili 第三方客户端。**

biliTv 以大屏和遥控器操作为核心：打开首页即可浏览推荐视频和频道内容，使用方向键选择视频并播放，也可以登录后查看个人观看记录和收藏内容。界面采用深色大屏布局，兼顾电视和触屏设备。

> 当前版本：**0.12.1**

## 功能一览

- **频道与发现**：浏览首页推荐、全站及分区榜单、主题内容轨道；可选择固定频道，并调整轨道顺序和显示状态。
- **视频播放**：支持视频分 P、观看进度续播、画质选择、音轨、倍速、字幕和弹幕；播放规格会结合接口返回和设备能力调整。
- **弹幕体验**：可开关弹幕，并调整显示区域、速度、字号、透明度和密度。
- **个人内容**：登录后查看观看历史、稍后再看和收藏夹，关注 UP 主并浏览其主页和投稿。
- **大屏操作**：针对电视遥控器优化焦点与方向键导航；同时支持安卓平板的触屏使用。
- **播放设置**：可配置首页布局、频道与轨道，以及默认画质、视频编码等偏好。

## 下载与安装

前往 [GitHub Releases](https://github.com/lvsaber01/biliTv/releases/latest) 下载当前版本 APK，并在 Android TV、电视盒子或安卓平板上安装。Android 可能需要允许当前文件管理器安装未知来源应用。

发布版本和每次更新的内容请查看 [版本记录](CHANGELOG.md)。

## 使用说明

- 浏览公开内容不要求登录；观看历史、收藏、稍后再看和关注等个人功能需要登录 Bilibili 账号。
- 视频清晰度、编码和播放线路受视频本身、账号权限、网络状况及设备解码能力影响；可用选项可能不同。
- 本项目使用 Bilibili 相关接口，服务端策略或接口变化可能影响部分功能。
