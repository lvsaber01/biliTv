# 弹幕详细设置（0.6.0）

## 目标与确认范围

2026-10-23 用户确认：独立弹幕分类，加入覆盖范围、速度、字号、不透明度、密度、恢复默认；播放器保留开关并增加定向入口。全局持久保存，返回播放器生效，不重建播放源。

现有 XML 接口和登录规则不变，不新增依赖、网络请求或权限。不包含关键词屏蔽、顶/底固定弹幕、智能防遮挡或弹幕发送。XML 中的条目仍按滚动弹幕展示，不宣称支持原始弹幕类型。

## 设置项

| 项目 | 可选值 | 默认 |
|---|---|---|
| 显示 | 开/关 | 开 |
| 覆盖范围 | 视频画面上方 25% / 50% / 75% / 全屏 | 50% |
| 速度 | 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 倍 | 1 倍 |
| 字号 | 小 / 标准 / 大 | 标准（18 dp 基准） |
| 不透明度 | 25% / 50% / 75% / 100% | 75% |
| 密度 | 低 / 中 / 高 | 中 |

覆盖范围基于 fit 模式下的视频可见画面，不含上下或左右黑边，从顶部开始计算。不是遮挡人物识别。

速度相对视频时间，1 倍约 6 秒从右侧完整穿过，2 倍约 3 秒；暂停时冻结，倍速视频下同步加快，快进/后退立即重算可见弹幕。调整速度可能使当下弹幕重新定位，这是确定性时间映射而不是重新发起播放。

密度为同屏上限 12 / 24 / 40 条，不保证一定填满。覆盖区域小、字号大或评论密集时，空间不足会跳过部分评论，不排队补发积压。简单轨道碰撞检测减少同轨文字重叠，不承诺智能防遮挡。

## 交互与兼容

- 设置 → 弹幕；播放器顶部 → 弹幕设置，直接打开该分类。另保留播放设置入口。
- 延续双栏焦点：右键进入内容，左键回当前分类，上下逐项移动，确认循环选项。触摸可点击切换。
- 恢复默认需确认，只恢复弹幕分类，不改变画质、编码、布局或观看进度。
- 返回播放器后应用最新配置，保持原播放器实例、进度与播放/暂停状态；焦点保留在原入口。
- 旧版本只有弹幕开关，升级后保留开关，其他项使用本表默认值；非法值回退默认值。
- 失败/无弹幕/加载中状态继续沿用原来的提示与重试逻辑。

## 实现与验收

AppSettings 持久化 DanmakuSettings，读取/保存校验值域；设置循环控件持有真实选项，不通过文字反查值。渲染仅在数据、视频尺寸或设置变化时重建轨道，时间窗口二分查找，避免每 100 ms 遍历整份 XML。

验收覆盖：所有选项循环及持久化、旧设置升级、非法值回退、覆盖裁切与视频黑边、速度实际位移、暂停/快进后退、密度上限、开关状态、分类恢复默认、播放器返回不重启、左右栏焦点。关联修复需验证列数 2 → 3 → 1 → 2，以及我的 → 设置 → 返回恢复设置卡片（包含改设置/不改设置）。Shield 真实解码与云历史继续独立验收。
