# biliTv 0.5.0 导航、个人中心与统一续播

## 确认后的范围

将顶部频道条改为悬浮深色导航，内容频道滚动渐隐，搜索、我的、历史固定；首页与更多也保留固定入口。增加独立历史网格，设置拆分横屏左右面板，个人中心与收藏页统一卡片风格。所有普通视频入口共享观看进度；普通卡片仍进入详情，历史卡片直接回看。

## 导航及设置

- 导航与内容分别布局，保留顶部安全空间。遥控器焦点边框与当前页面选中底色分离，频道获得焦点不会请求内容，确定后才切换。
- 顶部固定：首页、更多、搜索、我的、历史。中间启用的频道横向滚动并两端渐隐。设置入口位于我的空间，频道管理和播放器设置快捷入口保留。
- 设置分为外观与布局、频道与轨道、浏览与加载、播放、账号与存储、关于。左侧分类，右侧独立滚动面板，切走保留各面板位置。
- 分类上按右进入对应设置项；返回先回当前分类，再返回退出。设置即时保存。分类恢复默认只恢复该分类；频道和轨道保留各自已有的恢复按钮。
- 首页管理打开首页轨道，更多管理定位顶部频道设置，频道内管理定位对应频道轨道，播放器设置定位播放面板。
- 退出登录、清理封面缓存先确认。缓存清理仅删除应用自有 covers-v1 下的图片和临时图片，保留 SQLite 进度及偏好设置；异步图片任务使用代次防止旧请求重新写入缓存。

## 历史与个人中心

- 未登录显示登录邀请；已登录读取云端历史，按今天、昨天、具体日期分组显示封面、作者、观看时间、分 P 及有效进度。
- 历史点击/确定直接回看；长按打开详情。分页由 max、view_at、business 游标推进，重复游标或空页终止。
- 进入历史时合并当前账号最近的本机记录，读取云端页面后补充；相同 BV 显示最新一次观看。失败保留已加载卡片，失效会话提供重新登录入口。
- 个人中心使用头像/昵称/状态账号卡，及收藏、历史、设置功能卡。收藏夹和收藏内容均使用卡片，支持追加与返回收藏夹。

## 续播规则

- 普通卡片保留进入详情的流程，封面底部显示细进度条，文字显示已看时间与分 P。详情主按钮显示继续播放，旁边可从头播放。
- 历史入口先获取最新视频详情，确认 cid 仍在分 P 列表中，再打开播放器，避免直接使用失效分 P。
- 每个账号、BV、cid 独立保存位置；普通入口按最新观看记录选择分 P，用户显式选择其他分 P 时只使用该分 P 的记录。
- 完播、无效 cid、零/越界进度不续播。分 P 消失时回到第一 P；新时长短于记录位置时从头播放。
- 播放结束标记完成；接近结束的判断为剩余不超过 min(30 秒, 总时长 5%)，且进度达到 95%，避免短视频刚开始就被判为看完。
- 画质/编码切换使用当前播放位置和暂停状态。系统重建通过 savedInstanceState 保留当前位置。

## 数据与账号隔离

- ProgressRepository 使用单独有界串行线程访问 SQLite，界面读取内存索引。每 5 秒保存；暂停、离开播放器和完播时补存。
- 未登录记录保存在 guest；登录记录优先按 Cookie 中的 DedeUserID 分区。缺少 UID 时使用会话 SHA-256 摘要作为独立命名空间，不记录原始 Cookie。
- 云端 progress 单位秒，view_at 单位秒，转换到毫秒；progress=-1 表示已看完，其他负数按无有效进度处理。
- 本机与云端按观看时间比较，更新的记录优先；同时间保留本机已有记录。按 cid 存储，按 BV 聚合最新观看位置。
- 历史请求验证发起账号并固定该次请求的会话 Cookie；返回时再次核对账号，旧账号结果不能合并到新账号。
- 应用恢复前台重新识别账号，更新当前卡片进度；登录/退出后清除旧个人页面缓存。数据库保留各账号独立的进度，退出后不显示到访客。
- 云端仅按需读取：启动/返回时限频读取最近一页，历史页按游标追加。不遍历整份历史为每张卡片查询，也不向云端上报本机进度。
- 进度更新只改进度条、文字或详情按钮，不重载普通卡片封面，也不重建频道轨道。

## 验证与限制

- JVM 测试覆盖完播阈值、时间比较、有效进度、多 P 选择、显式从头播放、失效分 P、变化时长、账号命名空间与跨账号写入拒绝。
- Robolectric 覆盖真实 SQLite 写入/重新读取、历史 JSON 字段及游标解析、六类面板创建、600px 横屏固定导航布局，以及进度刷新不替换封面。
- 本地测试和测试响应不上传 Git；测试依赖仅作用于 JVM 测试，APK 不包含 Robolectric。
- 公开匿名历史请求实测返回 -101，验证未登录分支。当前无设备或真实登录态可验证云端历史内容；解析测试使用构造响应，不能替代真实账号验收。
- 尚需设备检查：登录后分页、账号切换、跨设备进度合并、播放器真实 seek、多 P、暂停/返回、画质切换、遥控器路径、触摸与视觉效果。
