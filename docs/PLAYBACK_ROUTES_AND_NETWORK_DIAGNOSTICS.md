# 播放线路与网络诊断

## 背景与目标

当前播放接口已经返回主播放地址和备用地址，但播放器此前只使用主地址；“线路”按钮也只能展示当前 CDN 主机，不能手动切换或判断网络问题。本功能包在不引入代理服务器、不上传诊断数据的前提下，补齐线路候选、自动切线、手动选线和当前会话诊断。

## 当前状态与问题

- `/x/player/wbi/playurl` 已返回 DASH 视频/音频和 MP4 地址。
- `VideoTrack`、`AudioTrack` 已解析 `backupUrl` / `backup_url`，但原 Media3 数据源没有使用这些候选。
- 播放器能够显示错误并切换低一级画质，但不能区分线路网络错误和解码能力错误。
- 网络诊断只能显示当前主机，缺少首帧、缓冲和连接探测数据。

## 本次范围

- 将主线路和备用线路组装为当前画质/编码的 `PlaybackRouteSet`。
- 对 MP4 和 DASH 视频/音频使用线路感知的 Media3 `DataSource`。
- 连接失败、超时和可恢复 HTTP 错误时自动尝试备用线路。
- 全部线路失败后刷新一次签名播放地址；保留播放位置、播放状态、画质、编码、字幕和弹幕设置。
- 播放器线路面板只显示“主线路 / 备用线路”短标签、当前状态和最近探测等级；主机名等详细信息收拢到网络诊断页。
- 设置增加“网络与线路”分类：自动切线、线路策略和诊断结果清理。
- 网络诊断显示网络类型、首帧、缓冲次数/时长、自动切线次数和最近错误；用户主动触发当前线路小范围 Range 探测。

## 不在范围内

- 不建立代理、中转或 VPN。
- 不修改 Bilibili 返回的签名 URL。
- 不后台持续测速，不扫描局域网。
- 不把完整签名 URL、Cookie 或账号信息写入日志、设置或上传远端。
- 不把某个 CDN 域名永久固定为全局偏好。

## 用户流程与页面布局

### 播放器线路面板

遥控器确认播放器“线路”按钮后打开单选列表。焦点默认落在当前线路；上下选择，确认后保留进度重建播放器，返回关闭面板并回到播放控制栏。面板显示短标签、最近探测等级和“网络诊断”入口；域名不占用电视播放选择界面。

### 自动切线

播放器只在线路网络连接、超时、HTTP 错误和可恢复的线路级清单错误时，按有限次数尝试下一候选；解码器、HDR、DRM、会员权限和其他格式错误不切换 CDN。候选全部失败后只刷新一次播放地址，避免无限重试。

### 网络诊断页

从播放器线路面板或设置进入。页面使用现有深色横屏布局和 `NestedScrollView`，提供当前网络、播放会话、线路结果和“测试全部线路”。探测每条线路的视频地址，并在存在音频地址时一并探测；单个请求只读取最多 64 KiB。

## 设置项与默认值

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 播放失败自动切换线路 | 开启 | 仅处理网络类错误 |
| 线路策略 | 自动选择 | 自动模式允许备用线路成功后提升当前会话线路 |
| 优先主线路 | 可选 | 每次新请求优先从主线路开始 |
| 仅使用主线路 | 可选 | 用于排查备用线路或网络行为 |

签名地址只在进程内当前播放会话存在，设置只保存策略，不保存 URL。

## API、缓存与失败回退

不增加 Bilibili API。播放接口继续使用 `/x/player/wbi/playurl` 和旧接口回退，读取 `durl`、`dash.video` 和 `dash.audio` 中的主/备用地址。

线路探测使用当前响应中的签名地址，通过 HTTPS、Referer、Origin、User-Agent 和 Range 请求模拟最小播放读取。连接超时为 2.5 秒，读取超时为 4 秒，结果只在内存保留约一个播放会话，不写磁盘。

## 方案与取舍

采用“线路感知 DataSource + 播放器级刷新兜底”：DataSource 负责打开和读取阶段尝试候选，播放器负责在全部候选耗尽后刷新签名地址以及处理手动选线。相比只在 `onPlayerError` 中重载，能覆盖 DASH/MP4 的打开和读取失败；相比后台测速，不会产生持续额外流量。

所有网络探测和播放地址请求使用有界线程池，不在主线程执行，也不因线程池繁忙回退到主线程。

## 验收标准

- 无备用地址时，仍能按原逻辑播放，不增加等待循环。
- 主线路不可连接时，播放器能自动尝试备用线路并保留位置。
- 所有候选失败后只刷新一次播放地址，最终错误面板提供重试、低画质和线路选择。
- 手动选线只影响当前视频，不污染下一个视频和全局设置。
- DASH 视频/音频线路切换后仍使用有效的两路地址；没有音频备用地址时保留主音频。
- 线路面板的焦点、返回、确认和错误面板焦点在 TV 遥控器上连续可用。
- 诊断页面能展示网络类型、首帧、缓冲、切线次数和最近错误。
- 测试请求最多读取 64 KiB，完整签名 URL 不出现在日志和持久化文件中。
- 单元测试覆盖候选排序、备用音频补齐、测速等级和原有播放/画质回归。
